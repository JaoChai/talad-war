# Talad War v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A mobile-first browser game (local play vs bots) where Team Fruit and Team Thai Dessert grab falling crates, stack them on their pad into recipes (gun / bombs / teammate), and win by destroying the enemy stall — deployed on Cloudflare at a shareable URL.

**Architecture:** npm-workspaces monorepo. `packages/sim` is a pure, deterministic TypeScript simulation (fixed 20 Hz tick, seeded RNG, `step(state, inputs) → state`, bots included) with no Phaser/DOM imports — the future online Durable Object will run this same package. `apps/client` is Phaser 4 + Vite; it only turns touch/keyboard into `UnitInput`, runs the sim locally and renders with interpolation. Hosting is Workers Static Assets (assets-only, no backend in v1).

**Tech Stack:** Node 24, TypeScript 6.0.3, npm workspaces, Vitest 5.0.2, Phaser 4.2.1, Vite 8.3.1, @cloudflare/vite-plugin 1.60.2, Wrangler 4.141.0, @playwright/test 1.63.0, ESLint 10 + Prettier 3.9 (same pins as `~/Code/dice-bandits`, which is the proven reference layout).

**Spec:** `docs/2026-10-14-talad-war-design.md` (owner-approved 2026-10-14; decisions Q1–Q9 + Builder calls §8).

**Documentation Basis:**
- Cloudflare: an assets-only site needs `assets.directory` + `assets.not_found_handling: "single-page-application"`; with the Vite plugin a Wrangler file is optional for assets-only, but we keep one to pin `name` and `compatibility_date` (developers.cloudflare.com/workers/static-assets/routing/single-page-application, changelog 2025-12-08).
- Phaser: only 2 pointers exist by default (`mousePointer` + `pointer1`); joystick + a button at the same time needs `input.activePointers` in the game config (max 10) (docs.phaser.io InputManager.addPointer).
- Future online (not v1): a Durable Object running a live tick is billed wall-clock for the match; one room lives in one location.

## Global Constraints

- Sim package (`packages/sim`) imports nothing from Phaser, DOM, `Date`, `Math.random` or `performance`; all randomness comes from the seeded RNG stored in `MatchState`.
- Fixed tick `TICK_HZ = 20` (`DT = 0.05` s). Client renders at display rate and interpolates between the last two sim states.
- v1 scope: 1 map, 2 teams (`'fruit' | 'dessert'`), 3 units per team at start, team cap **5**.
- Recipes v1, exact shapes only: 1 crate → `gun`; 2 adjacent ground crates → `bombs` (3 uses); 1 column of 2 → `buddy`. Anything else → `null` ("not a recipe yet").
- Placement (Q8): stand on a pad floor cell; empty column → ground layer, occupied → upper layer, full → no-op + shake event. Empty-handed Pick/Drop on an occupied own cell lifts the top crate. "Open!" exists only at own pad with a valid recipe; open takes **1.0 s** (20 ticks).
- Loadout (Q9): one gun slot + one bomb stack. Death drops everything; respawn empty-handed at own stall after **5 s** (100 ticks) while the stall stands.
- Win (Q5): a stall reaching 0 HP ends the match; the other team wins.
- Mobile: landscape only; portrait shows a rotate prompt. Left joystick, right buttons Pick/Drop + Fire (auto-aim nearest enemy unit or stall in range) + Throw (only while bombs > 0, shows count) + Open! (only when valid) + 3 squad commands Attack / Guard / Fetch. Desktop: WASD, mouse aim + click fire, E = Pick/Drop and Open (Open wins when visible), Q = Throw, 1/2/3 = commands.
- UI strings Thai first, all in one table `apps/client/src/i18n/th.ts` (English later). No text painted inside art.
- First playable load ≤ **5 MB** total transferred; 60 fps target on a mid-range phone.
- Music default volume 0.3, ducked under explosions.
- Balance targets (bot vs bot): median match **5–8 min**; each side wins **45–55 %** over 1000 matches.
- Out of v1 (spec §7 non-goals): online, accounts, unlocks, stats, more maps, vehicles, heavy weapons, bonus crates, stealing from enemy pad, character switching, split-screen.

## Review Focus

1. Two units press Pick/Drop on the same crate in the same tick → exactly one gets it, decided by ascending unit id (deterministic). Test in Task 2.
2. A carrier is hit while standing on a pad cell, a stall, or the arena edge → the dropped crate lands at the nearest free walkable ground point, never inside a stall or outside the arena. Test in Task 2.
3. Pad contents change during the 1 s open (teammate lifts a crate, a new crate placed) → the open cancels with no item. Buddy recipe at team cap 5 → not openable, preview reason `'teamFull'`. Test in Task 3.
4. Joystick held while tapping Fire / Pick → both register (needs `input.activePointers: 4`). Test in Task 8 (Playwright multi-touch via CDP `Input.dispatchTouchEvent`).
5. Tab hidden / phone backgrounded mid-match → the sim pauses; on return it does not run a burst of hundreds of catch-up ticks (accumulator clamped to 5 ticks). Test in Task 8.

```ts
export type Team = 'fruit' | 'dessert';
export type UnitId = number; export type CrateId = number;
export interface Vec2 { x: number; y: number }
export interface UnitInput {
  move: Vec2;            // length ≤ 1
  aim: Vec2 | null;      // world point; null = auto-aim (Task 4)
  fire: boolean; throwBomb: boolean; pickDrop: boolean; open: boolean;
}
export type SquadCommand = 'attack' | 'guard' | 'fetch' | null;
export interface Unit { id: UnitId; team: Team; isBot: boolean; pos: Vec2; facing: Vec2; hp: number;
  carrying: CrateId | null; gun: { ammoCooldownTicks: number } | null; bombs: number;
  deadUntilTick: number | null; }
export interface Crate { id: CrateId; pos: Vec2; state: 'falling' | 'ground' | 'carried' | 'onPad';
  landTick: number; }
export interface Pad { team: Team; origin: Vec2; cells: (CrateId | null)[][]; /* [col 0..3][layer 0..1], col = 2x2 floor index */
  opening: { byUnit: UnitId; doneTick: number; snapshot: string } | null; }
export interface Stall { team: Team; pos: Vec2; hp: number }
export interface MatchEvent { tick: number; kind: string; [k: string]: unknown }
export interface MatchState { seed: number; rng: number; tick: number; units: Unit[]; crates: Crate[];
  pads: Record<Team, Pad>; stalls: Record<Team, Stall>; projectiles: Projectile[];
  commands: Record<Team, SquadCommand>; winner: Team | null; events: MatchEvent[]; nextId: number; }
export function createMatch(seed: number, opts?: { humanUnit?: UnitId | null }): MatchState;
export function step(s: MatchState, inputs: ReadonlyMap<UnitId, UnitInput>, commands?: Partial<Record<Team, SquadCommand>>): MatchState;
export function stateHash(s: MatchState): string;
export function nextRandom(s: MatchState): number; // [0,1), advances s.rng
```

`Projectile` is declared here as `{ id; team; kind: 'bullet' | 'bomb'; pos; vel; ttlTicks }` and used from Task 4. `events` holds only the events of the latest tick (the client reads them for SFX/FX).
